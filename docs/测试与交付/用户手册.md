# 课程注册系统用户手册

适用版本：main `d8c6235`。本手册汇总自成员 2 的页面和运行说明，操作已按当前代码核对。

## 1. 安装与启动

需要 Python 3.12 或更高版本和 MySQL 8。

先在 MySQL 中建好数据库和账号：

```sql
CREATE DATABASE course_registration CHARACTER SET utf8mb4;
CREATE USER 'course_user'@'127.0.0.1' IDENTIFIED BY '自己设定的密码';
GRANT ALL ON course_registration.* TO 'course_user'@'127.0.0.1';
```

然后在项目根目录执行（`--database-url` 中的用户名、密码、端口、库名按本机实际填写）：

Windows（PowerShell）：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m scripts.run_demo --database-url 'mysql+pymysql://course_user:密码@127.0.0.1:3306/course_registration?charset=utf8mb4'
```

Linux / macOS：

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m scripts.run_demo --database-url 'mysql+pymysql://course_user:密码@127.0.0.1:3306/course_registration?charset=utf8mb4'
```

如果系统没有 Python 3.12（例如 Ubuntu 22.04 自带 3.10），可以用 uv 安装：`uv venv --python 3.12 .venv`，再执行 `uv pip install --python .venv/bin/python -r requirements.txt`。

也可以把连接地址写进环境变量 `DATABASE_URL`，之后直接运行 `python -m scripts.run_demo`。启动时会自动建表并初始化演示数据。

启动后打开 `http://127.0.0.1:8000/login`。在启动终端按 Ctrl+C 停止。再次启动会保留原有数据和密码。

| 情况 | 处理 |
| --- | --- |
| 提示端口被占用 | 加参数 `--port 8900 --catalog-port 8911 --billing-port 8912` |
| 连接 MySQL 失败 | 检查 MySQL 是否启动、账号密码和端口是否正确、账号是否有该库权限 |
| 查看运行日志 | `tmp/run-demo-端口号/` 下的 app、catalog、billing、worker 日志 |
| 想恢复到初始数据 | 停止系统，在 MySQL 中删除并重建该数据库，删除项目根目录的 `mock_billing.db`（计费模拟账本），再启动 |

数据库密码只写在本机命令或环境变量里，不要提交到 GitHub。

## 2. 账号

| 角色 | 账号 | 初始密码 |
| --- | --- | --- |
| 教务 | registrar | Initial123 |
| 学生 | S001–S010 | Initial123 |
| 教师 | T001–T010 | Initial123 |

第一次登录会进入“修改密码”页。新密码至少 8 位，需同时包含字母和数字。改密后需用新密码重新登录。教务新建的师生账号初始密码也是 `Initial123`。

## 3. 学生

| 菜单 | 用途 |
| --- | --- |
| 选课目录 | 查看本学期课程、教师、上课时间、正式人数（自动刷新）、先修要求。为班次选择“主选”或“备选” |
| 选课草稿与排序 | 调整备选顺序，保存草稿或提交正式选课 |
| 正式选课结果 | 查看已选上的班次和备选，单独退课或删除整份方案 |
| 我的成绩 | 查看各学期成绩 |

规则：

- 第一次提交必须正好 4 个主选、2 个备选。之后修改可以是 0–4 个主选、0–2 个备选。
- 保存草稿不占名额，提交时才检查名额、先修课和时间冲突。任何一门不满足，整次提交不生效，原来的正式结果保留。
- 同一课程只能选一个班次。换班时在草稿里用新班次替换旧班次后再提交。
- 主动退课后，系统不会自动用备选补上。
- 同时在两个页面修改时，后保存的页面会提示“方案已在其他页面更新，请重新载入”。刷新后再操作即可。
- 教务关闭选课后只能查看，不能修改。关闭时系统会取消没有教师或不足 3 人的班次，并按备选顺序替补。

## 4. 教师

| 菜单 | 用途 |
| --- | --- |
| 班次认领 | 查看有资格教授的班次，点“认领该班”或“取消认领” |
| 授课花名册 | 选择自己的班次，查看正式选上的学生 |
| 成绩录入 | 默认显示上一个已完成学期的班次，录入 A、B、C、D、F、I 或留空，点“保存并提交成绩” |

规则：只能认领有资格的课程；与自己已认领班次时间冲突时会提示是哪个班次冲突；已被别的老师认领的班次不能认领；选课关闭后不能再认领或取消。只有学期已关闭选课且结束日期已过，才能录成绩。每次修改都会留下变更记录。

## 5. 教务

| 菜单 | 用途 |
| --- | --- |
| 师生人员管理 | 新增学生或教师（编号自动分配），修改姓名、出生日期、社会保障号码、档案状态、院系、毕业日期；启用 / 停用账号；重置密码；删除 |
| 关闭选课控制台 | 选择学期，输入 `CLOSE-CONFIRM` 后二次确认，关闭选课并生成账单任务 |
| 结果与账单状态 | 查看取消班次数、选课人数、每位学生的金额和账单发送状态；立即派发账单；对停止重试的账单“重新排队” |

说明：

- 新增教师必须填写院系。
- 有选课、成绩或账单历史的人员，点删除会变为停用，以保留历史记录。停用后该用户立即被登出。
- 关闭成功表示结果和金额已固定。账单是否已被计费系统收到，要看“账单发送状态”。计费系统暂时不可用时，后台每隔一段时间自动重发，不需要人工操作。只有被计费系统明确拒绝的账单才需要处理后点“重新排队”。

## 6. 常见提示

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 首次登录必须先修改密码 | 账号仍是初始密码 | 进入修改密码页 |
| 课程目录暂时不可用 | 外部目录服务未启动或超时 | 稍后重试；已保存的选课不受影响 |
| 班次 X 已满 | 名额已被占满 | 换其他班次 |
| 先修课程未满足 | 没有通过先修课 | 选其他课程 |
| 班次 X 与班次 Y 上课时间冲突 | 时间重叠 | 去掉其中一门 |
| 本学期选课已经关闭 | 教务已关闭选课 | 只能查看结果 |
| 只能录入已完成学期的成绩 | 学期未关闭或未结束 | 等学期结束后录入 |
