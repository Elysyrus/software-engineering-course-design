## 1. 公共前置条件

1. 清空重建 MySQL 验收库 `course_acceptance_test`，执行 `alembic upgrade head` 与 `scripts.seed_final_demo`。
2. 目录服务加载 `acceptance_catalog.json`，执行 `scripts.sync_catalog` 导入 2027-SPRING，再执行 `setup_acceptance_data.py` 补充教师资格。
3. 计费服务使用持久账本，`BILLING_RETRY_SECONDS=1`。
4. 除 TC-AUTH-01～06 外，所有账号已完成首次改密（新密码 `Accept2027a`）。
5. S001–S003 在 2025-FALL 已有 FINAL001 成绩 B（满足 ACC107 先修）；S004 及新建学生没有。
