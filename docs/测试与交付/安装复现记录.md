## 2. 安装 MySQL 8.0.42

| 步骤 | 实际结果 |
| --- | --- |
| 下载官方包 `mysql-8.0.42-linux-glibc2.17-x86_64-minimal.tar.xz` | 成功，MD5 与官方 `.md5` 文件一致 |
| 缺少 `libaio.so.1` | 用 `apt-get download libaio1` 取得 deb，解包到 MySQL 目录，通过 `LD_LIBRARY_PATH` 加载 |
| `mysqld --initialize-insecure` | 成功，数据目录 `~/.local/mysql-run/data` |
| 启动 | 只监听 127.0.0.1:3307，关闭 X 协议 |
| 自带 `mysql` 客户端 | 缺少 libncurses5，无法使用；改用项目里的 pymysql 建库建用户 |
| 建库 | `course_registration_test`、`course_acceptance_test`，以及复现用的 `course_repro`；专用账号只授权这几个库 |
| `pymysql[rsa]` 连接（caching_sha2_password） | 成功 |

停止 MySQL：结束 mysqld 进程即可。删除 `~/.local/mysql-8.0.42` 和 `~/.local/mysql-run` 可以完全卸载。
