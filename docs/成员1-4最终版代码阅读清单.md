# 成员 1–4 最终版代码阅读清单

核对日期：2026-10-08。代码基线：main 的最终统一版本；本清单已按清理后的目录更新。

下面按原六人分工划分最终版的阅读和解释责任。它不是逐行代码作者统计；最终版包含各成员提交和 AI 在统一集成时新增、修改的代码。请大家阅读最终版，不再只阅读各自旧分支。

路径均相对于项目根目录。每人先读 README.md 和 docs/最终版运行与验证说明.md，运行自己模块的一次完整操作，再按下面顺序追踪代码。

## 阅读后的最低要求

本轮必须理解：每个主要文件做什么，选一次自己的实际操作说明输入、处理过程、数据库变化和输出；正常与失败场景各能说明一个；能够运行自己的模块并解释相应测试在验证什么。

本轮不要求脱离参考重写整个模块。暂可直接复用密码哈希库、模板引擎、数据库框架的内部实现，但要知道调用位置、参数和结果。阅读、运行通过与独立实现能力分别记录；个人总结按实际贡献填写。

课程题目、PPT 要求、封面模板、需求草稿和原分工统一在 docs/课程材料/。数据库迁移保留完整链，它们依次参与升级，不是可删的旧副本。
